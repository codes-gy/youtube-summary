# 웹 화면은 내 컴퓨터에서만 열리고 한 번에 작업 하나만 돌린다

`ytdoc serve`는 영상 파일을 받고, 내 컴퓨터의 Claude 사용량과 CPU를 쓰고, 만든 PDF를 내준다. 그래서 `127.0.0.1`에만 바인딩한다. 또 모든 요청의 `Host`가 `127.0.0.1:<포트>`나 `localhost:<포트>`여야 하고, 작업을 만드는 요청은 `Origin`도 같은 주소여야 한다(PR #4, 67c1283). `Host` 검사는 DNS rebinding을 막는다. 도메인을 127.0.0.1로 다시 가리키게 한 웹 페이지가 작업 상태를 읽거나 PDF를 받아 가지 못하게 하는 것이다. 다른 기기에서 접속하는 기능은 이 보안 경계와 맞바꿨다.

## Consequences

- 작업은 큐에 쌓이고 워커 하나가 차례로 처리한다. 받아쓰기는 CPU·GPU를 다 쓰므로 동시에 돌려도 빨라지지 않는다.
- 작업 목록은 메모리에만 있다. 작업 번호는 시각(마이크로초)으로 정하므로, 서버를 다시 켜도 `outputs/<번호>.pdf`를 덮어쓰지 않는다(2010c90).
