# 단계 결과는 이름에 버전을 넣은 JSON 파일로 캐시한다

영상 하나를 처리하는 데 몇 분이 걸리고 Claude 호출에는 돈이 든다. 그래서 각 단계의 결과를 `.ytdoc_cache/<영상 ID 또는 file-해시>/`에 JSON으로 저장하고, 그 파일이 있으면 단계를 건너뛴다(`src/cache.rs`). 파일은 임시 파일에 쓴 뒤 이름을 바꾸므로, 중간에 멈춘 실행은 그대로 다시 실행하면 이어진다. 데이터베이스나 무효화 로직은 두지 않았다. 대신 결과를 바꾸는 입력과 결과의 형식을 파일 이름에 넣는다. 예를 들어 `summary.v2.<문서 언어>.<Whisper 모델>.json`, `transcript-fixes.v1.<모델>.json`이다.

## Consequences

- 단계 결과의 형식이나 뜻이 바뀌면 파일 이름의 버전을 올려야 한다. 그대로 두면 옛 캐시가 조용히 다시 쓰인다. 개념·관계·비교표를 더할 때 `summary.v2`로 올렸다(4e1c880).
- 버전이 아직 없는 파일(`meta.json`, `frames.json`, `translation.<언어>.<모델>.json`)의 형식을 바꿀 때는 버전을 새로 붙인다.
- PDF와 Obsidian 노트는 캐시하지 않고 매번 다시 만든다. 템플릿만 바꿨다면 다시 실행해도 Claude를 부르지 않는다.
